# 📊 E-Commerce Sales Dashboard

An interactive Power BI dashboard built to analyze e-commerce sales performance using SQL Server, Excel, and Power BI.

---

## 🚀 Project Overview

This dashboard provides insights into sales performance, customer behavior, and product category trends through interactive visualizations.

### Key KPIs
- 💰 Total Revenue
- 👥 Total Customers
- 📦 Total Orders
- 💳 Average Order Value

---
